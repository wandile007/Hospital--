# Health++ - Hospital Management System

## 📋 Description
A comprehensive hospital management system built with modern web technologies. This application allows hospitals to manage patient records, doctor schedules, appointments, and medical documentation efficiently.

## 🎯 Features
- **Patient Management:** Register and manage patient information and medical history
- **Doctor Management:** Manage doctor profiles, specializations, and availability
- **Appointment Scheduling:** Book and track patient appointments
- **Medical Records:** Secure storage and retrieval of patient medical documents
- **User Authentication:** Secure login system for doctors and staff
- **Responsive UI:** Works on desktop and mobile devices

## 💻 Tech Stack

**Backend:**
- C# / ASP.NET Framework
- Entity Framework (ORM)
- SQL Server Database

**Frontend:**
- React JS (basics)
- HTML5 / CSS3
- Bootstrap 5

**Tools:**
- Visual Studio
- Git & GitHub
- SQL Server Management Studio
